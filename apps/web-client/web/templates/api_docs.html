API Documentation

Access government data programmatically through our REST API.

Getting Started

The OpenDiscourse API provides access to government data including member profiles, bills, votes, and discrepancies. All endpoints return JSON data and are accessible via standard HTTP requests.

Base URL
https://opendiscourse.example.com/api
Authentication

Most endpoints do not require authentication. Rate limiting may apply to prevent abuse.

Rate Limiting

API requests are limited to 1000 requests per hour per IP address. Exceeding this limit will result in a 429 (Too Many Requests) response.

Endpoints

Members

Retrieve information about government members.

GET /api/members
GET /api/members/{person_id}
Bills

Retrieve information about legislation.

GET /api/bills
GET /api/bills/{bill_id}
Discrepancies

Retrieve identified discrepancies between voting records and public statements.

GET /api/discrepancies
Search

Search across all data types.

GET /api/search?q={query}&type={type}
Statistics

Retrieve platform statistics.

GET /api/statistics

Example Usage

Retrieve a list of government members:

curl -X GET "https://opendiscourse.example.com/api/members?page=1&per_page=20"

Search for bills related to healthcare:

curl -X GET "https://opendiscourse.example.com/api/search?q=healthcare&type=bills"

Get platform statistics:

curl -X GET "https://opendiscourse.example.com/api/statistics"
