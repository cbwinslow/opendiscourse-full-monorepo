About OpenDiscourse

Promoting government transparency through data analysis and public engagement.

Our Mission

OpenDiscourse aims to increase government transparency by providing a platform that tracks and analyzes the voting records and public statements of government officials. We believe that an informed citizenry is essential for a healthy democracy.

How It Works

Our platform collects data from multiple government sources, including:

  • OpenStates - State legislative data
  • Congress.gov - Federal legislative data
  • GovInfo.gov - Official government publications
  • OpenLegislation - New York State legislative data

We then analyze this data to create comprehensive profiles of government officials and identify potential discrepancies between their voting behavior and public statements.

Key Features

Member Profiles

Detailed profiles of government officials with voting records, sponsored bills, and public statements.

Discrepancy Detection

Automated identification of potential inconsistencies between voting behavior and public positions.

Search & Discovery

Powerful search capabilities to find members, bills, and legislation across all levels of government.

API Access

Comprehensive API for developers and researchers to access our data and build their own applications.

Technology

OpenDiscourse is built with modern web technologies:

  • Python/Flask backend for data processing and API services
  • PostgreSQL database for data storage
  • Bootstrap 5 for responsive frontend design
  • RESTful API architecture

Data Sources

All data is sourced from official government APIs and publications, ensuring accuracy and reliability. We do not collect any private or personal data beyond what is publicly available from government sources.
