# Copilot Instructions for OpenDiscourse

## Project Overview

OpenDiscourse is a comprehensive platform for analyzing and processing both media intelligence and government documents. The platform combines advanced data processing capabilities with modern web technologies to deliver intelligent document analysis and retrieval-augmented generation (RAG) capabilities.

## Technology Stack

### Core Technologies
- **Frontend**: Next.js 14+ with App Router, React 18+, TypeScript
- **Backend**: FastAPI (Python), PostgreSQL with pgvector
- **Database**: Supabase (self-hosted via Docker)
- **AI/ML**: LocalAI for inference, Ollama for local LLM agents
- **Infrastructure**: Docker, Docker Compose, Kubernetes-ready
- **Styling**: Tailwind CSS, Radix UI components
- **State Management**: React Query, Zustand
- **Authentication**: Supabase Auth

### Project Structure
```
opendiscourse/
├── web/                    # Main Next.js App Router application
├── webui/                  # Legacy Pages Router application (being phased out)
├── opendiscourse/          # Python backend package
├── api/                    # FastAPI backend
├── supabase/              # Supabase configuration and migrations
├── docker/                # Docker configurations
└── opendiscourse-docs/    # Documentation with agent instructions
```

## Development Guidelines

### Next.js Best Practices

#### App Router (Preferred)
- **Use `/web` directory** for all new frontend development
- **Server Components by default**: Use React Server Components unless client interactivity is needed
- **Client Components**: Mark with `'use client'` only when necessary (forms, event handlers, browser APIs)
- **Route Structure**: Follow App Router conventions in `src/app/`
- **Loading States**: Use `loading.tsx` files for route-level loading
- **Error Handling**: Implement `error.tsx` files for error boundaries
- **Metadata**: Use Next.js metadata API for SEO

#### Modern Next.js Features
```typescript

  const documents = await getDocuments(); // Direct async in Server Component
  return <DocumentsList documents={documents} />;

// Example: Client Component for interactivity
'use client';
import { useState } from 'react';

export function SearchForm() {
  const [query, setQuery] = useState('');
  // Interactive logic here
}
```

#### Performance Optimizations
- **Image Optimization**: Use `next/image` with proper sizing
- **Dynamic Imports**: Use `next/dynamic` for code splitting
- **Bundle Analysis**: Run `npm run analyze` to check bundle size
- **Caching**: Leverage Next.js built-in caching and revalidation

#### Authentication Flow
```typescript
// Server Component auth check
import { createServerComponentClient } from '@supabase/auth-helpers-nextjs';
import { cookies } from 'next/headers';

export default async function ProtectedPage() {
  const supabase = createServerComponentClient({ cookies });
  const { data: { session } } = await supabase.auth.getSession();
  
  if (!session) redirect('/login');
  return <DashboardContent />;
}
```

```typescript

  });
```
